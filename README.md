# MovieVault - Frontend

MovieVault es una aplicación web para descubrir y gestionar una colección personal de películas. Permite explorar un extenso catálogo, buscar por título, organizar películas vistas y pendientes, y acceder a información detallada como trailers oficiales. El frontend está construido con tecnologías modernas como Next.js y React.

## Características

- **Exploración de Películas**: Navega por un extenso catálogo organizado por categorías.
- **Búsqueda Avanzada**: Encuentra películas específicas mediante búsqueda por título.
- **Gestión de Colecciones**: Añade películas a tu colección personal y marca su estado como "Visto" o "Pendiente".
- **Reproductor de Trailers**: Visualiza trailers oficiales directamente en la aplicación.
- **Experiencia Personalizada**: Crea una cuenta para mantener tu colección sincronizada.
- **Interfaz Adaptativa**: Diseño responsive que se adapta a todos los dispositivos.
- **Animaciones Fluidas**: Experiencia de usuario mejorada con animaciones optimizadas.

## Tecnologías Utilizadas

- **Frontend**: Next.js, React, TypeScript
- **Estilización**: Tailwind CSS, shadcn/ui
- **Animaciones**: Framer Motion
- **Autenticación**: Sistema de tokens JWT
- **API Externa**: The Movie Database (TMDb)

## Librerías y herramientas principales

- **next.js**: Framework de React para aplicaciones web.
- **framer-motion**: Librería para animaciones fluidas.
- **tailwind-css**: Utility-first CSS framework.
- **shadcn/ui**: Componentes de UI accesibles y personalizables.
- **embla-carousel**: Carruseles optimizados para móviles.

## Estructura del Proyecto

- app: Páginas y rutas de la aplicación (Next.js App Router)
- components: Componentes reutilizables de la UI
- hooks: Custom hooks de React
- lib: Utilidades y servicios de APIs
- public: Archivos estáticos

## Páginas Principales

- **Home**: Página de inicio con información destacada.
- **Explorar**: Catálogo completo de películas por categoría.
- **Búsqueda**: Encuentra películas específicas.
- **Mi Colección**: Gestiona tu lista personal de películas.
- **Perfil**: Edita tu información de usuario.
